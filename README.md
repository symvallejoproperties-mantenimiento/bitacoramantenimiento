# Centro de Operaciones de Mantenimiento

Aplicación estática para Vallejo Properties construida con HTML, CSS y
JavaScript. No requiere servidor, framework ni proceso de compilación.

## Uso

1. Abra `index.html` desde un servidor estático o GitHub Pages.
2. Use **Cargar Excel** para seleccionar una versión actualizada de
   `Centro de Operaciones.xlsx`.
3. Los filtros, indicadores, alertas, gráficas y tablas se recalculan en el
   navegador.

La carpeta completa puede publicarse directamente en GitHub Pages. El archivo
`data/default-data.js` contiene la versión inicial de los datos; cargar un Excel
desde la interfaz no modifica archivos y mantiene la información únicamente
durante la sesión actual.
